    Dotdown

    一个用 Tauri 打造的 Markdown 预览 / 编辑小工具

    功能

    • 代码库阅读：打开文件夹浏览源码，查看 Git 分支、变更、暂存区 / 工作区差异和最近提交；源码以只读方式打开
    • 分栏编辑：左侧源码（CodeMirror）+ 右侧实时预览（markdown-it）
    • 多标签页：并行打开多个文档，按路径去重，未保存以 ● 标记
    • 会话恢复：重启自动还原上次打开的标签
    • 最近打开：工具栏「最近」下拉一键重开近期文件
    • 大纲侧栏：标题目录，点击平滑跳转
    • 深色模式：浅色 / 深色 / 跟随系统三态切换
    • 设置面板：齿轮按钮汇集主题、字号、自动换行、大纲，改动即时生效
    • 视图切换：编辑 / 分栏 / 预览；编辑器 → 预览滚动同步
    • 查找替换：Ctrl+F 查找、Ctrl+H 替换，编辑器与预览均可逐个高亮跳转
    • 字数统计：底部状态栏实时显示字数 / 字符 / 行，选区另计
    • 标签拖拽：拖动标签即可重排顺序
    • GitHub 风格渲染：表格、任务列表、代码高亮
    • 公式 / 流程图：$..$ 数学公式（KaTeX）、```mermaid 流程图
    • 导出 PDF / HTML / Word：可导出为 PDF、自包含 HTML 或可编辑的 Word 文档（.docx）
    • 拖拽打开：把 .md 文件拖进窗口即可打开

    快捷键

    Ctrl+N / Ctrl+T新建标签
    Ctrl+O打开
    Ctrl+S保存
    Ctrl+Shift+S另存为
    Ctrl+W关闭当前标签
    Ctrl+\开关大纲侧栏
    Ctrl+F查找（编辑器 / 预览）
    Ctrl+H替换（编辑器）
    Ctrl+P导出 PDF

    技术栈

    Tauri 2 · Vanilla TS + Vite · CodeMirror 6 · markdown-it · highlight.js
